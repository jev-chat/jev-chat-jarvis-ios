## 常见问题

**键盘没有出现？** 在 iPhone“设置 > 通用 > 键盘 > 键盘 > 添加新键盘”中添加“Jev 键盘”，再在输入框中通过地球键切换。密码框等安全输入区域可能只允许系统键盘。

**看不到候选回复？** 在系统键盘设置中为 Jev 键盘开启“允许完全访问”；在应用“模型”页填写你自己的生成服务地址、模型和 API Key，并先点“测试连接”。如果所选服务需要付费或限制访问，请向服务商确认。

**如何使用？** 在聊天应用中复制要回复的消息，切到 Jev 键盘，点“分析剪贴板”。也可以点“分析输入框文字”处理已经输入的内容。点候选会插入文字；键盘“发送”键输入换行符，宿主应用可能据此发送消息。

**为什么需要完全访问？** 键盘联网调用你配置的模型服务、读取剪贴板及共享应用配置需要此系统开关。应用不会持续上传按键内容；只有主动分析时才会发送所选文字。你可以随时在系统设置中关闭完全访问或移除键盘。

**怎样清除数据？** 在“模型”页清空 API Key、更改服务地址，并删除不再需要的自定义话术；删除应用和键盘扩展后，本机配置按 iOS 的卸载机制处理。已发往模型服务的内容需向该服务商查询或申请删除。
