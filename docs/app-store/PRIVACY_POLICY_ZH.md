## 1. 我们处理什么信息

- **用户主动分析的文字**：当你点击“分析剪贴板”“分析输入框文字”或在应用内运行分析时，应用读取对应文字，用于判断意图和风险、生成和排序候选回复。文字可能包含聊天消息、输入框内容及你自行填写的其他信息。应用不会为了生成回复而持续监听按键，也不会在未触发分析时主动读取剪贴板。
- **模型配置和 API Key**：你填写的服务地址、模型、API Key、额外请求字段、自定义话术及语言设置保存在设备的应用配置中，并由主应用和键盘扩展共享。API Key 不上传到 Jev Jarvis 自有服务器；为调用你配置的服务，密钥会作为请求凭据发送给该服务。当前实现使用本地 App Group `UserDefaults` 保存配置，并非单独的 Keychain 存储。
- **键盘状态**：键盘最近打开时间、是否获得“允许完全访问”等状态保存在本机，供应用显示启用状态。应用不会为此建立用户账户。
- **临时分析结果**：当前消息、候选回复和判断结果会在运行时内存中使用；同一消息的判断结果可能在内存中缓存约 5 分钟，以加快再次分析。应用没有将聊天正文保存到自有服务器的功能。

## 2. 何时联网，以及数据发往哪里

你可以自行配置生成服务；判断与排序服务可单独配置，也可以不启用。点击分析时，应用可能将待分析文字、生成所需的话术说明和候选回复发送到你配置的生成服务与判断服务。点击“测试连接”时，应用会向相应服务发送内置测试文字。启用“允许完全访问”且已配置生成服务后，键盘打开时还可能向该服务请求模型列表以预热连接；这项请求携带 API Key，但不携带聊天正文。

这些服务可能是你选择的第三方 AI 服务、网关或本地服务。服务商可能接收请求内容、API Key、IP 地址和连接信息，并按其自身政策处理、保存或跨境传输。请在填写密钥前阅读所选服务商的隐私政策与服务条款。Jev Jarvis 不控制第三方服务的保存期限、模型训练设置或所在地区。应用支持用户填写 HTTP 地址；HTTP 传输可能未经加密，请优先使用 HTTPS，不要将敏感内容发往不可信端点。

## 3. 剪贴板、键盘与“允许完全访问”

“允许完全访问”是 iOS 对第三方键盘开放联网、读取剪贴板和共享配置所需的系统设置。授予该权限本身不会让应用持续上传按键内容。你可以在 iOS“设置 > 通用 > 键盘 > 键盘”中随时关闭该权限或移除 Jev 键盘；关闭后依赖联网和剪贴板的功能将无法正常使用。

候选回复由你点按后插入当前输入框。键盘上的“发送”按钮会向当前输入框输入换行符；是否由聊天应用将换行视为发送，取决于该应用。Jev Jarvis 不会在没有你操作的情况下自动发送消息。

## 4. 处理目的、共享与保存期限

上述信息只用于提供你请求的分析、生成、排序、连接测试、键盘状态显示与本机设置同步。当前版本未集成广告或分析 SDK，也不使用这些信息进行跨应用跟踪或出售个人信息。

本机配置会保留至你修改配置或删除应用；运行时分析数据随进程结束而消失，判断缓存最长约 5 分钟。第三方服务的留存期限由你选择的服务商决定。本应用无法替第三方服务删除其已收到的数据。正式发布的构建不会记录聊天正文；开发调试构建可能写入诊断信息。

## 5. 你的选择与删除请求

你可以不启用 Jev 键盘、不授予“允许完全访问”、不填写服务密钥，或随时停止分析。你可以在应用内更改服务地址、清空密钥和自定义话术；删除应用和键盘扩展后，本机数据按 iOS 的卸载机制处理。如需询问本应用的数据处理或提出删除请求，请联系上述邮箱；涉及模型服务留存的数据，请同时向相应服务商申请。

## 6. 儿童与政策更新

本应用并非面向儿童设计。请不要通过应用处理你无权使用的聊天内容，也不要在未了解所选模型服务政策时发送敏感个人信息。政策重大变更会在公开政策页面更新生效日期；如数据处理方式发生实质变化，应在应用内作相应告知。
