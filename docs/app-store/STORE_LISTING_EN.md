## Description

Jev Jarvis is a keyboard for drafting chat replies. Copy a message, switch to the Jev keyboard, and tap Analyze Clipboard to see reply ideas alongside the current conversation. You can also analyze text already in the input field.

Choose a tone and tap a suggestion to insert it into the input field. You decide whether to send it. The keyboard's Send key inserts a newline, which some chat apps may treat as a send action.

Features:

• Reply suggestions for each selected tone, with custom tones available.
• Optional intent and risk analysis, plus suggestion ranking, when you configure a judge provider. Drafting still works without one.
• Chinese and English interfaces, selectable on the Home tab.
• Bring your own API key and OpenAI-compatible or Anthropic-compatible generation service. Jev Jarvis provides no built-in model service or relay.

Analysis starts only when you request it. The selected text is sent to the model services you configure, which may process it under their own policies. Network and clipboard features in the keyboard require Allow Full Access in iOS Settings. Read the privacy policy and your chosen provider's terms before use.

Third-party keyboards may be unavailable in secure text fields. Check important information before using a model-generated reply.
