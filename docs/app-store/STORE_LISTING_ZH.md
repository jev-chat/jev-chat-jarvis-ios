## 副标题

## 宣传文本

复制消息，在键盘中主动分析并获取不同语气的回复建议。模型服务由你配置，候选回复由你选择。

## 描述

Jev Jarvis 是一款聊天回复辅助键盘。复制需要回复的消息，切换到 Jev 键盘并点按“分析剪贴板”，即可在当前输入框旁查看候选回复；也可以分析输入框中已输入的文字。

你可以选择话术风格，点按候选将文字插入输入框。是否发送由你决定。键盘上的“发送”键会输入换行符；聊天应用可能把换行解释为发送。

主要功能：

• 每个启用的话术提供不同表达的回复建议，并支持自定义话术。
• 配置判断服务后，可查看意图、风险提示及候选排序；未配置时仍可生成候选。
• 支持中文和英文界面，在应用“开始”页切换。
• 自行配置兼容 OpenAI 或 Anthropic 接口的生成服务和 API Key；Jev Jarvis 不提供内置模型服务或中转。

分析由你手动触发。所选文字会发送到你配置的模型服务；服务商可能按照自己的政策处理数据。键盘内联网和读取剪贴板需要在 iOS 设置中开启“允许完全访问”。请在使用前阅读隐私政策以及所选服务商的条款。

第三方键盘可能无法在密码框等安全输入区域使用。模型输出仅供参考，重要信息请自行核对。
